# Superstore Sales Analysis

A data analysis project that explores Superstore transaction records to uncover patterns in sales, profit, discounts, products, customer segments, regions, and performance over time.

## Project Objective

The project transforms retail data into useful business insights by exploring questions such as:

- How do sales and profit change over time?
- Which categories and sub-categories perform best?
- Which regions and customer segments generate the most value?
- How are discounts related to profitability?
- Which products or areas may require business attention?

## Dataset

The Superstore dataset contains transactional data with **21 columns**, including:

- Order and shipping dates
- Customer and segment information
- City, state, and region
- Product category and sub-category
- Sales, quantity, discount, and profit

## Analysis Workflow

1. Import and inspect the dataset
2. Review data types, missing values, and duplicate records
3. Convert date columns into datetime values
4. Clean and prepare the data
5. Engineer time-based features
6. Analyze monthly sales and profit trends
7. Compare categories, sub-categories, regions, and segments
8. Visualize important business patterns

## Business Areas Explored

- Sales performance over time
- Profitability by category and sub-category
- Regional performance
- Customer segment performance
- Discount and profit relationships
- Product-level trends

Open `final-Analysis.ipynb` or `analysis_supstore.ipynb`, keep `Superstore.csv` in the repository root, and run the cells in order.
